## 补充（同日）：修复「登录后空白」

### 根因
`App.tsx` 把动态菜单生成的 `<Route>` 数组作为 children 传给 `<Layout>`，而 `Layout.tsx` 在 `<main>` 里**直接渲染 `{children}`，没有包 `<Routes>`**。React Router v6 规定 `<Route>` 只能是 `<Routes>` 的直接子元素，直接渲染抛出：

```
Uncaught Error: A <Route> is only ever to be used as the child of <Routes> element
```

未捕获错误导致 React 整棵树卸载 → 登录后全白（登录页本身不含动态 Route 所以正常）。

### 修复（Layout.tsx）
1. `{children}` 包进 `<Routes>`
2. 加 `<Route path="/" element={<Navigate to={firstPath} replace/>}>`——firstPath 取自菜单树里第一个 type=2 且有 path 的菜单（默认 /dashboard），否则访问 `/` 内容区空白
3. 加 `path="*"` 的兜底「页面不存在」

### 验证
无头自动登录（临时 public/_dev_autologin.html 注入 token 后跳转，已删）：/dashboard 渲染完整（侧边栏+统计卡+图表+系统状态），/system/user 正常出列表数据，console 无 Uncaught；tsc --noEmit 通过。
